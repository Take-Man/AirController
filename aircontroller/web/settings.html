AirController 設定

run: —

確定した値は、動いている run にもすぐ反映されます（使う手とオン・オフと省電力の項目は、run を起動し直すと反映）。確定のたびに履歴（settings-history/）が残ります。

測定

calibrate を別のウィンドウで起動します。結果は候補として下に並び、確定するまで使われません。各見出しの「U◯ 測定」からも測れます。

測定の候補

効果の見積もり

基準記録（eval-manifest.toml）を、保存済みの値と、比べる値で流して差を出します（約 20 秒）。

履歴

名前を付けた状態

保存の履歴（新しい順、最新 50 件）

ライブ

run に接続していません

run の起動中に、手の形と今の値を出します。この画面を開いている間、run は「設定モード」になり、出力を止めます。 変更中の値は run で試せます（確定するまで保存しません。画面を閉じると、run は確定済みの値に戻ります）。

AirController

—
環境のチェック権限・カメラ・キーボードが使える状態かを確かめます チュートリアルジェスチャーと操作を、見て・試して覚えます 設定反応の速さや、ピンチなどの効き方を合わせます

使い方

  • 「開始」で、カメラと手の読み取りを始めます（画面の右上に小さな表示が出ます）。
  • 右 Command を単独で押して離すと、操作のオン・オフを切り替えます。オフの間に手のひらをカメラに向けて 0.5 秒保っても、オンになります。
  • 操作中に手が 5 秒見えないと、自動でオフになります。
  • すぐに止めるときは、Control + Option + Command + ピリオド。
  • うまく動かないときは「環境のチェック」を、反応を合わせるときは「設定」を開いてください。
